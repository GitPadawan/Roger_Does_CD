# Christmas-theme fix — existing GitHub Pages installation (v0.4 to v0.5)

Upload **both** `app.mjs` and `sw.js` into the **root** of your existing `roger-does-countdown-solo` GitHub repository, replacing the current copies. Do not change your GitHub Pages URL or create another repository.

Keep the iPhone/iPad online. Open the site's normal HTTPS address in Safari, then refresh. As the previous offline service worker caches files, you may need to close/reopen the Home Screen game or reload again before the new version appears. Select **Christmas** in the lobby: its background and Christmas tree should appear immediately, before starting a game. Switch to Classic and they disappear.

Only these two code files have changed. Your existing browser-stored MP3 is not committed, uploaded or replaced. This patch contains no MP3 and no private data.

For new installations, use the full `Roger_Solo_Pocket_v0.5_Christmas_Theme_Fix_GitHub_Safe.zip` instead.
